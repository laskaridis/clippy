## Codebase Patterns
- When multiple editable installs expose the same top-level package, verify `sys.meta_path` ordering; distribution naming can affect which checkout wins.
- Use frozen dataclasses for run-context and terminal outcome types so orchestration state stays immutable and easy to reason about.
- Keep built-in registries static and expose a dedicated lookup helper that raises a specific unknown-item error so callers can fail fast without inspecting the mapping directly.
- Load bundled prompt assets with `importlib.resources.files("ralph")` so prompt lookups work the same in editable installs and packaged wheels.
- Keep the orchestrator's step implementation imports local inside the run loop when the workflow module imports orchestrator types, so the package avoids circular import failures.
- Keep terminal presenters and JSONL emitters separate, then fan them out through a composite sink so human output and machine logs stay independently testable.
