## Codebase Patterns
- Run Ralph unittest discovery from the repository root with `PYTHONPATH=.` so `ralph.tests` resolves cleanly during `python -m unittest discover -s ralph/tests`.
- When using `sqlite3` connections in Ralph code, commit on success and close explicitly; the connection context manager alone does not close the handle.
- Use a singleton `active_lock` row in SQLite for run ownership, and only probe PID liveness for same-host locks.
- Derive the current session with `ORDER BY updated_at DESC, session_id DESC` when the store can contain multiple incomplete historical sessions.
- Run-only recovery should gate on the active lock state, reclaim only stale same-host locks, and ignore older incomplete sessions when starting a new session.
- In lock-inspection tests, patch `ralph.session._current_hostname` and `ralph.session._process_is_running` to exercise same-host and remote-host branches deterministically.
